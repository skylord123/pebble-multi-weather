Weather Providers

Enabled providers appear in the app. Drag handles to set the main menu order.

Test asks a provider for the weather where your watch is, so you can see it works there before saving.

    Quick Glance

    Choose what information displays below each provider name.

    Available Variables (click to insert)
    Temperature
    {temp} {temp_f} {temp_c} {temp_high} {temp_low} {temp_f_high} {temp_f_low} {temp_c_high} {temp_c_low}
    Wind
    {windspeed} {windspeed_mph} {windspeed_kph} {wind_direction}
    Conditions
    {humidity} {conditions} {forecast}
    Detailed Forecast

    Choose what information displays below each forecast period. High/Low temp requires hourly data coverage for the period.

    Available Variables (click to insert)
    Temperature
    {temp} {temp_f} {temp_c} {temp_high} {temp_low} {temp_f_high} {temp_f_low} {temp_c_high} {temp_c_low}
    Wind
    {wind} {windspeed} {windspeed_mph} {windspeed_kph} {wind_direction}
    Forecast
    {short_forecast} {long_forecast} {precip}
    Units

    When enabled, displays both °F and °C values.

    Menu Appearance

    Choose the menu background color. Sun Based switches between white (day) and black (night).

    Touch

    Tap to select, slide to scroll, hold for a long press, and swipe right to go back on watches with a touchscreen.

    Holding a finger on an item acts like holding the select button. Disable to use touch for navigation only.

    Saves to the watch and stays on this page

    Configure API Key

    Get your API key from OpenWeatherMap. Requires One Call API 3.0 subscription.

    The key is checked with the provider before it is saved.
