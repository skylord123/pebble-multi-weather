Weather Providers

Enabled providers appear in the app. Drag handles to set the main menu order.

    Quick Glance

    Choose what information displays below each provider name.

    Available Variables (click to insert)
    Temperature
    {temp} {temp_f} {temp_c} {temp_high} {temp_low} {temp_f_high} {temp_f_low} {temp_c_high} {temp_c_low}
    Wind
    {windspeed} {windspeed_mph} {windspeed_kph} {wind_direction}
    Conditions
    {humidity} {conditions} {forecast}
    Units

    When enabled, displays both °F and °C values.

    Menu Appearance

    Choose the menu background color. Sun Based switches between white (day) and black (night).

    Configure API Key

    Get your API key from OpenWeatherMap. Requires One Call API 3.0 subscription.
